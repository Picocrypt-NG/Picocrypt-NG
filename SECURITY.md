# Security policy

## Supported versions

Use the [latest stable release](https://github.com/Picocrypt-NG/Picocrypt-NG/releases/latest).
Reports about older releases and development builds are welcome. Include the
exact version or commit and, if possible, whether the issue also affects the
latest stable release.

## Reporting a vulnerability

Use GitHub's [private vulnerability report form](https://github.com/Picocrypt-NG/Picocrypt-NG/security/advisories/new).
Describe the impact, platform, affected version, and steps to reproduce.
Use sample files and credentials created for the report. Keep real passwords,
keyfiles, and private data out of reports and attachments.
